# LOCK IN
### Universal Study Planner

**Plan. Track. Achieve.**

LOCK IN is a minimalistic desktop study planner designed to bring structure to your studies without introducing unnecessary complexity.

It provides a dedicated space to organise study activities, manage schedules and maintain personal progress records.

---

## About the Project

LOCK IN began as a simple attempt to organise lengthy video lecture playlists.

What started as a small organisational tool gradually evolved into a standalone Windows desktop application.

The project was developed around a simple principle:

**A planner should organise the work, not do the work for you.**

LOCK IN emphasises personal responsibility and self-accountability rather than automated productivity measurements.

---

## Getting Started

### Requirements

- Windows operating system.
- Microsoft Edge WebView2 Runtime.
- Sufficient storage space.

### Installation

1. Visit the Releases section of this repository.
2. Download the latest available LOCK IN release.
3. Extract the downloaded archive.
4. Run `LOCK IN.exe`.
5. Begin setting up your planner.

---

## Data and Privacy

LOCK IN uses local data storage.

Your study records and planner information are maintained locally rather than requiring a cloud account.

Users are responsible for maintaining backups of their personal data.

Do not distribute your personal data file when sharing the application.
